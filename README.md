# Roteiro 4 — Herança, Composição e Interfaces (C#)

| Pasta | Exercício |
|-------|-----------|
| `Exercicio01-Heranca` | Classe `Veiculo` com as subclasses `Carro` e `Moto` |
| `Exercicio02-Composicao` | `Casa` que tem uma `Pessoa` |
| `Exercicio03-Interface` | Interface `IVeiculo` implementada por `Carro` e `Bicicleta` |
| `Exercicio04-MultiplasInterfaces` | Interfaces `IVoar` e `INadar` implementadas por `Pato`, `Aguia` e `Peixe` |

## Como executar

Cada exercício é um projeto de console independente (.NET 8):

```bash
cd Exercicio01-Heranca
dotnet run
```
